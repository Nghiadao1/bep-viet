# 🍜 Bếp Việt — Hành Trình Chinh Phục Ẩm Thực Việt Nam

Game nấu ăn đường phố Việt Nam theo phong cách pixel art 16-bit, đồng hành cùng **👑 Vằn Bếp Trưởng** (mèo tai cụp) và **🐾 Mèo Vàng Phụ Bếp** chinh phục ẩm thực 3 miền từ Sài Gòn, Huế, Hội An, Hà Nội đến ẩm thực Fusion!

## 🎮 Chơi Trực Tuyến

👉 **[Chơi ngay trên GitHub Pages](https://nghiadao1.github.io/bep-viet/)**

## ✨ Điểm Nổi Bật

- 🐱 **Cốt truyện 5 chương sống động:** Đồng hành cùng **Vằn Bếp Trưởng** & **Mèo Vàng Phụ Bếp** truy tìm *"Cuốn Sổ Vị Giác Việt Nam"*, tương tác trực tiếp ngay trên quầy bếp và trước mỗi màn chơi.
- 🍲 **24 món ăn đặc sản Việt Nam:** Phở Bò, Phở Gà, Bánh Mì Thịt, Cơm Tấm, Chè Ba Màu, Cà Phê Sữa Đá, Bún Bò Huế, Bánh Bèo, Bánh Nậm, Cơm Hến, Chè Huế, Mì Quảng, Cao Lầu, Bún Chả, Bún Đậu Mắm Tôm, Phở Cuốn, Phở Xào Truffle, Bánh Mì Wagyu...
- 🎯 **14 Mini Game nấu ăn tương tác chân thực:**
  1. 🔥 Thổi lửa đun nước dùng
  2. ⏱️ Căn nhịp cắt bánh phở
  3. 🔪 Kéo dao theo đường kẻ thái thịt & xẻ ổ bánh mì
  4. 🔥 Nướng bếp than hoa & lật 2 mặt vàng ươm
  5. 🥗 Nhặt rau thơm tươi sạch, né lá úa & sâu
  6. 🧂 Nêm gia vị & topping đúng khẩu vị khách *(thêm quẩy, tương ớt, pate, không hành...)*
  7. 🍳 Hất chảo xào lửa lớn theo vòng lửa
  8. ☕ Giữ & thả rót phân tầng Chè / Cà Phê
  9. 🌀 Xoay tròn đánh mắm tôm / pha nước chấm sủi bọt
  10. 🌯 Vuốt 3 bước cuốn Gỏi Cuốn / Phở Cuốn / gói Bánh Nậm
  11. 💧 Nhúng giỏ tre trụng phở & nhấc ráo đúng độ mềm
  12. 🍋 Vắt chanh tươi né rơi hạt vào tô
  13. 🧊 Đập tảng đá pha lê lấy đá viên mát lạnh
  14. 🎨 Đổ 3 chén Bánh Bèo Huế & rắc tôm cháy mỡ hành
- 🗺️ **Bản đồ Việt Nam hình chữ S:** Đầy đủ Phú Quốc, Côn Đảo, Quần đảo Hoàng Sa & Quần đảo Trường Sa.
- 📈 **50 màn chơi độ khó tăng dần đều:** Nhịp chơi gọn nhanh, nhận Rương Thưởng liên tục, nâng cấp quán tại Cửa Hàng Mèo Vàng.
- 📱 **Tối ưu điện thoại:** Hướng dẫn xoay ngang màn hình ngay khi mở trên di động, hỗ trợ cảm ứng mượt mà & toàn màn hình.

## 🛠️ Chạy Local

Yêu cầu Node.js 22+:

```bash
npm install
npm run dev      # Mở dev server tại http://localhost:5173
npm run build    # Build production ra thư mục dist/
npm run preview  # Xem trước bản build
```

## 💻 Công Nghệ

- TypeScript + Vite 6
- HTML5 Canvas 2D (thuần, không framework nặng)
- 41 sprite Pixel Art 16-bit + hiệu ứng hạt 60fps
- Lưu tiến trình bằng LocalStorage
- Tự động deploy GitHub Pages qua GitHub Actions (`.github/workflows/deploy.yml`)
