# 🍜 Bếp Việt — Vietnamese Street Food Cooking Game

A casual time-management cooking game featuring authentic Vietnamese street food!

## Play

👉 **[Play Online](https://catking-play-time.github.io/bep-viet/)** (Coming soon)

## About

Start from a humble street cart in Saigon selling phở, grow your restaurant empire across Vietnam — from Huế's royal cuisine to Hà Nội's old quarter specialties!

### Features
- 🍲 22+ authentic Vietnamese dishes with real cooking steps
- 🗺️ 5 chapters across Vietnam (Sài Gòn → Huế → Hội An → Hà Nội → Fusion)
- 📈 50 levels with increasing difficulty
- 🏪 Restaurant upgrade system
- 🎨 Pixel art style with Vietnamese aesthetics
- 📱 Works on both desktop and mobile browsers

## Development

Requires Node.js 22+.

```bash
npm install
npm run dev      # Start dev server at http://localhost:5173
npm run build    # Build for production
npm run preview  # Preview production build
```

## Tech Stack

- TypeScript + Vite
- HTML5 Canvas 2D (no framework)
- LocalStorage saves
- GitHub Pages deployment
